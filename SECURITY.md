# Security policy

Please report suspected vulnerabilities through
[GitHub private vulnerability reporting](https://github.com/onOEXL/oexl/security/advisories/new),
not a public issue.

Include the affected package and commit, a minimal reproduction, expected
impact, and any suggested mitigation. Do not include live credentials, private
keys, personal data, payment information, or third-party repository contents.

OEXL public packages are pre-release. Security fixes target the latest version
on `main`; no long-term-support branch is currently maintained.

The public packages do not operate the matching engine, settlement system, or
hosted platform. Reports concerning those systems should still use private
reporting so maintainers can route them safely.
